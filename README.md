# K-BUSINESS DAY 2026 운영용 페이지

행사 운영에 쓰는 화면 파일을 두는 저장소입니다. 공식 안내는 https://www.k-businessday.com 에 있습니다.

| 경로 | 내용 |
|---|---|
| `/practice/` | 상담일지 연습(자유 입력) |
| `/practice-guided/` | 상담일지 연습(상황 지문과 모범 입력 비교) |
| `/guide/` | 참가기업용 거래 조건 제출 안내(초안) |
| `/log/` | 상담일지 시제품(가상 데이터) |

모든 화면은 가상 데이터만 담고 있으며, 실제 바이어·기업 정보와 단가는 이 저장소에 두지 않습니다.
